# 事業02: AIニュースレター

担当エージェント: `.claude/agents/newsletter-agent.md`

## 概要
AI・生産性ツール関連の実務者向けに、週刊(想定)で配信するニュースレター。

## 収益モデル
- 開始時は無料配信で購読者を増やす
- 一定規模に達したら有料プラン(Stripe連携)を検討

## 進行フェーズ(親セッション方針)
各事業共通で「1. 基盤の構築 → 2. プランの提示 → 3. 世に出す(公開)」の3ステップで進行。現在はフェーズ1(基盤構築)。

**基盤構築の定義(訂正版・2026-09-25):** 号のドラフト作成そのものは基盤構築ではなく後続フェーズの作業。基盤構築とは、事業運営に必要なプラットフォームへの登録・決済手段の確立を指す。具体的には下記セットアップチェックリストの「配信基盤(beehiiv/Substack)のアカウント開設」「配信用メールアドレス・ブランド設定」がこれにあたる。これらはユーザー本人の操作が必要なため、Claude Codeセッションは代行できず、スクリーンショット越しにユーザーをガイドする形で進める。基盤が整うまでは「プランの提示」フェーズに進まない。

実配信の開始・購読者募集の告知などユーザー以外の目に触れる「公開」作業(フェーズ3)に進む前には、必ず具体的な公開プラン(何を・いつ・どのように)をチャットでユーザーに提示し、承認を得てから着手する。
