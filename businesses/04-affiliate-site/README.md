# 事業04: アフィリエイト比較サイト

担当エージェント: `.claude/agents/affiliate-site-agent.md`

## 概要
生産性ガジェット/ソフトウェアサブスクリプションを中心に、カテゴリ別の比較コンテンツを提供するサイト。

## 収益モデル
- アフィリエイト報酬(Amazonアソシエイト、楽天アフィリエイト、各種ASP)

## セットアップチェックリスト(人間側)
- [ ] Amazon アソシエイト・プログラム申請
- [ ] 楽天アフィリエイト登録
- [ ] 承認後、`data/products.json` 内のプレースホルダーリンクを実リンクに差し替え
- [ ] ホスティング設定

## ディレクトリ構成
```
data/products.json   比較データ(価格・スペックは要確認フラグ付き)
site/index.html      比較ページ(products.jsonを読み込んで表示)
```

## 注意
価格・スペック等の数値は執筆時点で未確認のものが含まれる。公開前に必ず公式情報で検証すること。
