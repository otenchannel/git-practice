# 事業04: アフィリエイト比較サイト

担当エージェント: `.claude/agents/affiliate-site-agent.md`

## 概要
生産性ガジェット/ソフトウェアサブスクリプションを中心に、カテゴリ別の比較コンテンツを提供するサイト。

## 収益モデル
- アフィリエイト報酬(Amazonアソシエイト、楽天アフィリエイト、各種ASP)

## セットアップチェックリスト(人間側)
- [ ] Amazon アソシエイト・プログラム申請
- [ ] 楽天アフィリエイト登録
- [ ] 承認後、`data/products.json` 内のプレースホルダーリンクを実リンクに差し替え
- [ ] ホスティング設定

## ディレクトリ構成
```
data/products.json                  AIライティングツール比較データ
data/products-task-management.json  AIタスク管理ツール比較データ
data/products-meeting-notes.json    AI議事録・文字起こしツール比較データ
site/index.html                     AIライティングツール比較ページ
site/task-management.html           AIタスク管理ツール比較ページ
site/meeting-notes.html             AI議事録・文字起こしツール比較ページ
```

## 注意
価格・スペック等の数値は執筆時点で未確認のものが含まれる。公開前に必ず公式情報で検証すること。
