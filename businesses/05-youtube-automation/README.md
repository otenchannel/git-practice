# 事業05: AI自動運営YouTubeチャンネル

担当エージェント: `.claude/agents/youtube-agent.md`

## 概要
顔出し不要(フェイスレス)形式で、AI・テクノロジー解説動画を配信するチャンネル。台本→音声合成→動画組み立てのパイプラインを想定。

## 収益モデル
- YouTube広告収益(チャンネル登録者1,000人・総再生時間4,000時間などの条件達成後)

## セットアップチェックリスト(人間側)
- [x] YouTubeチャンネル開設
- [x] YouTube Data API 利用申請(アップロード自動化用)
- [x] 音声合成サービス(ElevenLabs等)アカウント開設
- [ ] 動画編集パイプライン(ffmpeg等)の環境構築

## ディレクトリ構成
```
scripts/   各エピソードの台本(Markdown)
pipeline/  台本→音声→動画の自動化スクリプト(ローカルPCで実行。詳細は pipeline/README.md)
```

## セットアップガイド
`SETUP_GUIDE.md` にチャンネル開設・API申請・音声合成アカウント開設の手順をまとめています。
`pipeline/README.md` に動画制作パイプライン(ffmpeg)のローカル実行手順をまとめています。
