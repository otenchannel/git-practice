# チャンネル基盤セットアップガイド(人間向け)

このガイドは、AI自動運営YouTubeチャンネルを実際に始めるために必要な、人間側の操作手順をまとめたものです。Claude Codeセッションはアカウント開設・API申請・決済設定などを代行できないため、ここに記載の手順はユーザー自身に実施していただき、操作中の画面をスクリーンショットで共有いただければ、次の手順や設定内容の確認をこのセッションでサポートします。

## セットアップ手順(概要)

### 1. YouTubeチャンネル開設
1. Googleアカウントで https://www.youtube.com/ にログイン
2. 右上のアイコン →「チャンネルを作成」を選択
3. チャンネル名・アイコン画像を設定(顔出し不要のAI/テック解説チャンネルとして、内容が伝わる名前を推奨)
4. チャンネル概要欄に、扱うテーマ(AI活用術など)を簡潔に記載

チャンネル名の候補や概要文の下書きが必要であれば、この場で作成できます。

### 2. YouTube Data API 利用申請(アップロード自動化用)
1. https://console.cloud.google.com/ にアクセスし、新規プロジェクトを作成
2. 「APIとサービス」→「ライブラリ」から「YouTube Data API v3」を検索して有効化
3. 「認証情報」から OAuth 2.0 クライアントIDを作成(アプリケーションの種類は用途に応じて選択)
4. 同意画面の設定(テストユーザーとして自分のGoogleアカウントを登録)
5. 発行されたクライアントID・シークレットは、公開リポジトリにコミットしないよう注意([要確認]: 実際の自動アップロード実装時に、安全な保管方法を別途検討)

このステップは技術的にやや複雑なため、画面をスクリーンショットで共有いただければ、各設定項目の意味や次に押すべきボタンをその都度案内します。

### 3. 音声合成サービス(ElevenLabs等)アカウント開設
1. https://elevenlabs.io/ など、音声合成サービスにアクセスしアカウント作成
2. 無料プランの制限(月間の文字数上限など)を確認([要確認]: 料金・上限は変更される可能性があるため公式サイトで最新情報を確認)
3. 日本語音声の品質をサンプルで確認し、チャンネルのナレーションに合う声を選定

### 4. 動画編集パイプライン(ffmpeg等)の環境構築
1. 台本(音声)+ 静止画やスライド + テロップを合成して動画化する手順を検討
2. 初期段階では、無料の動画編集ツール(Canva、CapCutなど)で手動組み立てから始め、慣れてきたらffmpeg等での自動化を検討するのが現実的([要確認]: 具体的なツール選定は今後の運用状況を見て判断)

## 進捗を共有する場合

操作中の画面をスクリーンショットで共有いただければ、次に何を設定すべきか、どの項目を埋めればよいか等をこのセッションで確認・案内します。

## 公開プランについて

上記の基盤(特にチャンネル開設)が整い次第、既存の台本(第1話〜第5話)を使って「何を・いつ・どのように公開するか」の具体的な公開プランをこのチャット上で提示し、承認をいただいてから実際の公開作業に進みます。
