# エピソード003: AIの出力を鵜呑みにしないためのチェック習慣

## タイトル案
1. AIの出力を鵜呑みにしないためのチェック習慣
2. 【地味に重要】生成AIの答えを信じすぎないための確認ポイント
3. その数値、本当に合ってますか?AI活用で見落としがちな確認作業

## サムネイル案
背景: シンプルなダーク背景 / テキスト: 「その数値、確認した?」を大きく / アイコン: 虫眼鏡とチェックマーク

## 想定尺
6〜8分

## 台本本文

### 導入(0:00-0:30)
生成AIはとても便利ですが、出てきた答えをそのまま使って、あとで間違いに気づいた、という経験はありませんか?今日は、AIの出力を安全に活用するための「ファクトチェックの習慣」について紹介します。

### 本編

**なぜファクトチェックが必要なのか**
生成AIは、もっともらしい文章を作るのが得意ですが、事実として正しいかどうかを保証する仕組みではありません。特に数値、固有名詞、日付、引用元などは、実際には存在しない情報が混ざることがあります。便利さと正確さは別の話だと意識することが第一歩です。

**優先的に確認すべき3つのポイント**
1. 数値・統計データ(件数、割合、金額など)
2. 固有名詞(製品名、企業名、人物名、法令名など)
3. 日付・最新情報(制度変更や新機能など、時期によって変わる情報)

これらは間違っていても文章としては自然に見えるため、特に注意が必要です。

**確認の具体的なやり方**
1. AIの出力の中で、数値・固有名詞・日付に印をつける
2. それぞれについて、一次情報(公式サイト、公式発表、一次資料)に当たる
3. 確認が取れないものは、そのまま使わず「要確認」として保留するか、表現を和らげる

一次情報が見つからない場合は、無理に断定的な表現を使わないことも大切です。

**チェックを習慣化するコツ**
毎回すべてを細かく確認するのは大変なので、「人に見せる前」「公開する前」など、チェックのタイミングをあらかじめ決めておくと続けやすくなります。

### まとめ(締め)
生成AIの出力は下書きとしては非常に優秀ですが、事実確認は人の役割として残ります。今日紹介したポイントを、次にAIを使うときにひとつだけでも試してみてください。
