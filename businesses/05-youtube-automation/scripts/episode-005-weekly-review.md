# エピソード005: 週1回の振り返りで、AI活用は驚くほど上達する

## タイトル案
1. 週1回の振り返りで、AI活用は驚くほど上達する
2. 【たった10分】AI活用を続けるための振り返り習慣
3. うまくいかなかった日こそチャンス、AI活用の振り返り術

## サムネイル案
背景: シンプルなダーク背景 / テキスト: 「週1回、10分だけ」を大きく / アイコン: カレンダーと振り返り矢印

## 想定尺
5〜7分

## 台本本文

### 導入(0:00-0:30)
AIツールを使い始めたけど、しばらくすると使わなくなってしまった。そんな経験はありませんか?今日は、そうならないための「週1回の振り返り習慣」について紹介します。

### 本編

**なぜ振り返りが必要なのか**
AI活用は、使えば使うほどコツがつかめていく分野です。しかし、使いっぱなしにしていると、うまくいったやり方もうまくいかなかったやり方も、記憶に残らずに流れていってしまいます。週に1回、短時間でも振り返る時間を作ることで、自分に合った使い方が少しずつ見えてきます。

**振り返りで確認する3つの質問**
1. 今週、AIが特に役に立ったタスクは何か
2. 今週、AIの出力を修正・破棄することが多かったタスクは何か
3. 来週、試してみたいプロンプトややり方はあるか

この3つを自分に問いかけるだけで、次の1週間の使い方が変わってきます。

**振り返りのやり方(実践編)**
1. メモアプリやカレンダーに「AI振り返り」の10分間を決めておく
2. 今週使ったプロンプトやAIとのやり取りをざっと見返す
3. 上記3つの質問に、1〜2行ずつ答えを書く
4. 良かったプロンプトはテンプレート集に追加し、うまくいかなかったものは修正するか削除する

特別なツールは不要で、普段使っているメモアプリだけで十分に始められます。

**続けるためのコツ**
毎週同じ曜日・同じ時間に固定すると習慣化しやすくなります。「完璧に分析する」のではなく、「気づいたことを1行書くだけでもOK」というくらい、ハードルを下げておくことが継続のポイントです。

### まとめ(締め)
今日紹介した週1回・10分の振り返りは、これまで紹介してきた4つの習慣(下書き活用、プロンプトの使い回し、ファクトチェック、作業の切り分け)を自分に定着させるための土台にもなります。今週から、カレンダーに10分だけ予定を入れてみてください。
