# 資料の入手計画(2026-10-30 版)

目的: 時代考証(`docs/knowledge-base.md`)に必要な「一次に近い史料」を、論文執筆(12/15〜)に間に合うよう入手する。
根拠: 台帳 `data/sources.csv`(S/L番号)、未解決の問い `data/open-questions.csv`(Q番号)、貸借メモ `docs/ill-request.md`、所蔵館 `data/holdings.csv`。

## 方針
- 待ち時間のかかるもの(ILL・複写・問い合わせ)を **先に発注** し、待っている間にオンラインで調べられるものを進める
- 市資料の利用条件(Q14/Q17)は、モデルの公開・論文掲載の可否に関わるため、**最優先で確認**
- 入手したら `sources.csv` の「入手状況」を更新し、根拠表(`evidence.csv`)に出典IDを書く

## 問い合わせの順番(依存関係)
1. 指導教員に、問い合わせの方針を相談(倫理審査の件と同時でよい)
2. 枚方市文化財課 → 利用範囲(Q14/Q17)、報告書の購入、冊子の購入、現地撮影の可否を **1通で** 問い合わせ
3. OIT図書館 → 報告書(第60集)と論文のILL・複写を依頼
4. 歴彩館 → 設計図の閲覧・複写・画像利用条件(文化財課の回答で、市の資料の扱いが分かってから送ると、説明がしやすい)

## 問い合わせ文の骨子
### 枚方市文化財課(資料を提供してくださった職員へ)
- 自己紹介(大阪工業大学の学生、卒業研究の題目)と、先日の資料提供へのお礼
- 確認したいこと
  1. 提供資料(彩色地形図・構造図・整備概要(案))を、卒業論文・発表・VR アプリ(非公開の学内実験)に利用してよいか。利用の範囲と、出典の書き方
  2. 報告書第60集(本編・史料編)と、解説冊子の購入方法
  3. 史跡公園での撮影(写真・必要なら実測)の条件、事前の手続き
- 研究の概要(1〜2文)と、希望の回答時期

### 歴彩館
- 設計図(『川々御普請定法書』貼付の絵図)の、閲覧・複写・撮影の条件、画像の利用許諾(論文掲載・学内発表・非公開 VR)の手続き、料金と所要日数
- 絵図の正式名(河州交野郡楠葉付関門絵図ほか)の確認(Q02)

### OIT 図書館
- 報告書第60集(本編・史料編)の相互貸借または文献複写。所蔵館の候補は `data/holdings.csv`
- 論文(ヒストリア206・217)の文献複写

## 注意
- 入手した資料の転載・公開は、各所蔵館の条件に従う。**非公開データは公開リポジトリに入れない**(`.gitignore`)
- 市資料に基づくモデルは、利用範囲の回答が出るまで、学内・研究室外に出さない
- 回答は **メールなど文書で残す**
