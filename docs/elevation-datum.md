# 標高の基準(Y=0)の決め方

## 結論
- **Unity の Y=0 = 淀川の水際の標高 5.0 m(東京湾平均海面 T.P. 基準)**。モデルの標高 Y は「T.P.標高 − 5.0 m」。
- 提供者の指示は「Y=0 を川底0m」。ただし**国土地理院のDEMは川底を測れない**(水面は欠測)。そのため、DEMで取れる最も近い値として水際の標高を基準にした。実際の川底ではない。
- 実測の川底標高(例: 淀川河川事務所の横断測量)が得られたら、`--datum-m` を差し替えて再生成する。

## 使ったデータ
国土地理院の標高タイル(DEM5A, 約5m格子)。`tools/fetch_gsi_dem.py` で取得、`tools/estimate_river_datum.py` で水際の標高を求めた。

| 項目 | 値 |
|---|---|
| 川(欠測領域)の縁の標高、半径500m | 中央値4.95 m(下位10% 3.67 m、上位75% 6.00 m) |
| 同、半径1km | 中央値5.10 m |
| 同、半径2km | 中央値4.97 m |
| **採用した基準(Y=0)** | **5.0 m** |

## 台場の標高(T.P. → Y)
地面は平滑化したDEM。番所の地面は13.2 m(Y=+8.2)で、東へ約2〜3m上がる(東の虎口で15.7 m、Y=+10.7)。部材ごとの値は `object-ledger.csv` の `ground_tp_m`。

## 限界
- 水際の標高は、水位の目安であって川底ではない(川底は水面の下に数m以上ある可能性)。
- DEMの測量年は未確認。現在の地形で、幕末の地面とは異なりうる(公園整備、鉄道の盛土、河川改修)。
- 地面は、土塁・堀の二重計上を避けるため、DEMを標準偏差12mのガウス平滑化で滑らかにして使っている。細かい起伏と、鉄道の盛土のような狭い構造物は消える。
- 土塁・堀・建物の高さは、この地面からの相対値(従来どおり)。
- 川の水面は欠測のため、周囲の縁の標高で埋めている。

## 再生成
```
python3 tools/fetch_gsi_dem.py 34.876650 135.680730 data/private/geo/dem
python3 tools/build_provisional_mesh.py data/private/geo/regions.json data/private/geo/object-map.json data/private/geo/mesh \
  --dem data/private/geo/dem/dem5a_z15.npy --dem-meta data/private/geo/dem/dem_meta.txt --origin 34.876650,135.680730 --datum-m 5.0
```
原点の緯度経度(34.876650, 135.680730)は、番所の位置を現在の地図に位置合わせして求めた値(誤差は数m〜十数m)。
