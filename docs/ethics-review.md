# 倫理審査の必要性(整理と問い合わせ案)

最終更新: 2026-10-26。**判断するのは大学(指導教員・研究室・倫理審査の窓口)であり、ここは確認のための整理。**

## 結論(暫定)
- この卒研は **人を対象とする実験**(被験者がVRを体験し、テストとアンケートに回答する)を含む。
- 多くの大学では、人を対象とする研究は、学部生の卒研でも「倫理審査を受ける」か「審査不要(非該当)の判断を受ける」のどちらかの手続きが必要になる。
- 大阪工業大学の規定は私(Claude)は確認できていない。**「不要」と決めつけず、実験(11/22〜)の前に、学内の窓口で要否の判断を文書で受ける**。予備実験(11/15〜)も被験者を使うため、その前に確認する。

## 審査が必要になりやすい点(この研究で当てはまるもの)
| 項目 | この研究 | 備考 |
|---|---|---|
| 人を対象とした実験 | 該当(各群10名前後+予備2〜3名) | 学生(成人)が対象 |
| アンケート・テスト | 該当(理解度テスト、関心・没入感、SUS、自由記述) | |
| 心身への影響 | VR酔いの可能性(SSQ簡易版で測定) | 体験は10分以内、中断の自由を明記 |
| 個人情報 | 取らない方針(匿名ID) | 氏名・学籍番号を記録に残さない運用が必要 |
| 画像・音声・動画の記録 | 予定なし | 撮影する場合は同意が別途必要 |
| 未成年・弱い立場の人 | 該当なし(同学科の学生) | 指導教員・成績との関係で強制にならないよう注意 |
| 利用資料 | 枚方市の資料(被験者には関係しない) | 倫理審査ではなく利用許諾(Q14, Q17)の問題 |

## 事前に確認すること(順に)
1. 指導教員(研究室)に、倫理審査の要否と窓口を聞く
2. 大学の研究倫理の規定・申請様式・審査の所要期間を確認する
3. 審査が必要な場合: 申請書、実験計画、同意書、説明文書、アンケート原本を揃えて提出
4. 審査不要の場合: その判断を **文書(メール可)で残す**
5. 実験の開始は、承認(または非該当の判断)が出てから

## 同意書・説明文書に入れる項目(案)
- 研究の目的と内容(楠葉台場のVR復元と、理解への効果の検証)
- 所要時間(約20〜30分)、体験は約10分
- 参加は自由で、いつでも理由なく中断・撤回できる。参加しなくても不利益はない
- VR酔い(気分が悪くなる可能性)と、その場合の対応(すぐ中断、休憩)
- 記録する情報(回答内容のみ。氏名等は取らない)と、匿名での扱い、保管場所・期間
- 結果の使い方(卒業論文・発表。個人が特定されない形)
- 連絡先(研究者と指導教員)
