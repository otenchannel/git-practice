# 評価設計(案)— 研究の主張④「根拠の提示が、利用者の理解に与える効果」

状態: 案(2026-11-13)。決めるのは学生と指導教員。倫理審査の要否が確認できるまで、被験者を使う作業は始めない。

## 1. 何を測るか(主要評価と副次評価)
**問い(RQ2)**: VR上で復元の根拠を示すと、利用者は、復元の「確かな部分」と「推定の部分」を見分けられるようになるか。

| 区分 | 指標 | 測り方 | 狙い |
|---|---|---|---|
| **主要** | 根拠の較正 | 体験後に、**8つの部分**(確認済み・史料に記載・類例から推定・資料不足を2つずつ)の信頼度(1〜5)を答えてもらい、**根拠の強い部分と弱い部分の信頼度の差**を人ごとに求める(補助として順位相関) | 信頼が、根拠の強さに応じて変わっているか |
| 副次 | 誤認率 | 推定を事実と言い切る文(誤りの文)を「正しい」と答えた割合。4文(誤り2・正しい2) | 推定を事実と取り違えていないか |
| 副次 | 確信度 | 文の真偽への自信(5段階) | 過信の有無 |
| 副次 | 確認問題(4問) | 解説に書かれた事実3問と、歩けば分かる事実1問。モデルを見ずに答える | 解説の効果と、空間把握の効果を区別 |
| 副次 | 関心・没入感・使いやすさ・VR酔い | 5段階の質問、SUS、簡易の酔い質問 | 体験の質と安全 |
| 行動 | 体験時間、クリックして解説を見た回数・対象 | アプリで記録(匿名ID) | 提示の使われ方(解説を読んでいない問題は分けて扱う) |

**ポイント**: 色の凡例を読めば解ける問題にしない。問題は、**モデルを見ない状態**で答えてもらい、**根拠表の記述**(`data/evidence.csv` の要素)から作る。提示のある群が、体験を通して根拠の構造を理解したかを測るため。

## 2. 比較する条件(案)
| 条件 | 内容 |
|---|---|
| 基本の2条件(推奨) | 〔提示なし〕自然色のモデルのみ / 〔提示あり〕根拠の色分けと、クリックでの解説(根拠を日本語で表示) |
| 余力があれば追加 | 〔色分けのみ〕クリック解説なし(色だけの効果を見る) |

- デザイン: 被験者間(同じ人に2回体験させない)。各群10〜15名、予備実験は各条件1〜2名。
- 学習効果と順序の影響を避けるため、割り当てはランダムに近い形で行う。
- 人数が少ないので、効果量と信頼区間を示す記述的な分析を中心にし、検定はMann-WhitneyのU検定とする。

## 3. 正解の作り方(妥当性)
- 「確かな/推定」の正解は、根拠表(`data/evidence.csv`)の根拠レベルによる。信頼度の8項目は、**資料で確かめられている要素**(虎口の基礎、北面の土橋、稜堡の形、番所の位置と大きさ)と、**推定・資料不足の要素**(番所の建築細部、淀川の流れ、火薬庫、砲)から作る。
- 根拠表の判断自体が、私たちの解釈である。問題文を確定する前に、指導教員か別の人に、根拠レベルの妥当性を確認してもらう。
- 注意: 現在のモデルの**位置・形**は、確認済み(A)の要素が無い(推定・演出)。そのため、問題は「要素の存在・性質」(文化庁の解説や発掘で確かめられているか)を問う形にし、「寸法の正確さ」を問わない。

## 4. 限界と対策
| 限界 | 対策 |
|---|---|
| 人数が少ない(検出できるのは大きな差のみ) | 効果量と信頼区間を示す。自由記述で補う。規模を小さくする場合は、基本の2条件に絞る |
| 根拠表の判断が研究者の解釈 | 第三者の確認。判断の根拠(出典ID)を、論文に付表として載せる |
| 提示ありの群が、凡例を暗記するだけの可能性 | モデルを見ない状態での判定、誤認を誘う文、確信度で測る |
| 被験者が同じ学科の学生(断りにくさ) | 参加は自由で、成績に関係しないことを明記し、教員が募集に関与しない |
| VR酔い | 体験は10分以内、中断の自由、低速の歩行 |

## 5. 決めること(学生と指導教員)
1. (決定済み)アンケートは圧縮案: 信頼度8+文の真偽4+確認問題4。確認問題は解説の内容に合わせた
2. 比較する条件を、基本の2条件にするか、3条件にするか(人数との兼ね合い)
3. 問題の数と、所要時間(体験10分、回答10分に収まるか)
4. 倫理審査の要否の確認(実験の前提)
