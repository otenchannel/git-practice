# 評価実験の設計(案)

## 目的
RQ2「VR体験は図面・解説パネルと比べて、台場の空間理解と歴史的関心を高めるか」を検証する。

## デザイン
- 被験者間比較: VR群 / 資料群(報告書の図面+解説パネル相当の資料)
- 人数の目安: 各群10〜15名(同学科の学生。予備実験は2〜3名)
- 所要時間: 1人20〜30分(説明5分、体験10分、回答10分)

## 指標
| 区分 | 内容 |
|---|---|
| 理解度テスト | 体験前後の同一形式テスト(台場の形状、砲座の数、淀川との位置関係、対岸台場との関係など)10問 |
| 主観評価 | 関心・没入感・理解しやすさ(5段階)、SUS(VR群のみ) |
| VR酔い | SSQ簡易版(VR群のみ) |
| 自由記述 | 良かった点・分かりにくかった点 |

## 手順
1. 同意取得・事前テスト
2. 体験(VR群: Unityアプリ / 資料群: 図面と解説)
3. 事後テスト・アンケート
4. 分析: 事前事後の得点差を群間比較(t検定またはMann-Whitney U検定)、自由記述は分類

## 注意
- 倫理審査の要否は大学の規定に従う(個人情報は取らない、同意書、中断の自由を明記)
- 問題文は根拠表(`data/evidence.csv`)の confirmed の要素から作り、推定部分を正解にしない
- VR酔い対策: テレポート移動を既定にし、体験は10分以内に収める

## 追加: 復元そのものの検証指標(資料集の提案を反映)
利用者実験とは別に、モデルの質を分解して評価する。「歴史的に正しい」という単一評価にしない。
| 指標 | 内容 |
|---|---|
| 位置精度 | 基準点に対する平均誤差・最大誤差 |
| 形状一致 | 設計図・発掘図の外郭線とモデルの平面差 |
| 証拠トレーサビリティ | 出典ID・図面頁・根拠区分を参照できる部材の比率 |
| 再現性 | 別の評価者が同じ資料から近い平面形を得られるか |
利用者実験の問題文は、根拠区分Aの要素から作る(`data/evidence.csv`)。B以下を正解にしない。
