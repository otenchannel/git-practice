## 実験者用の正答表(フォームには出さない)
### ページ4: 復元の8つの部分(信頼度)
| 項目 | 根拠の強さ(点数) |
|---|---|
| 火薬庫の位置と形 | 資料不足(1) |
| 南面の虎口(出入口)の基礎 | 確認済み(4) |
| 番所の屋根・壁・間取り | 類例から推定(2) |
| 南面・西面が突き出した角(稜堡)の形をしていたこと | 史料に記載(3) |
| 北面の虎口に土橋があったこと | 確認済み(4) |
| 大砲の種類・口径 | 資料不足(1) |
| 番所の位置と大きさ | 史料に記載(3) |
| 幕末当時の淀川の流れ | 類例から推定(2) |

- 主要評価(根拠の較正) = 根拠の強い部分(確認済み・史料に記載)の信頼度の平均 − 弱い部分(類例から推定・資料不足)の信頼度の平均。大きいほど、信頼を根拠の強さに応じて変えられている
- 参考: 各人の信頼度と根拠の強さ(A=4, B=3, C=2, U=1)の順位相関(Spearman)も、8項目から算出できる(不安定なので補助)

### ページ5: 文の真偽(誤認率)
| 文 | 正解 |
|---|---|
| 番所の屋根の形は、史料で確定している。 | 誤り |
| 北面の虎口の土橋は、発掘調査で確認されている。 | 正しい |
| 火薬庫の場所と形は、発掘調査で確かめられている。 | 誤り |
| 京街道が台場の内側を迂回していた痕跡は、発掘調査で確認されている。 | 正しい |

- 誤認率 = 「推定の部分を事実と言い切る文」(誤りの文)を「正しい」と答えた割合。正しい文を「誤り」と答える過剰な疑いも別に集計

### ページ6: 確認問題(種別つき)
| 設問 | 正解 | 種別 |
|---|---|---|
| 台場の南側にあった大きな堀は、何で造られていたことが、発掘で確認されていますか。 | 石垣 | 解説 |
| 北側の土手は、南側と比べて、どのような規模でしたか。 | 南側より小規模 | 解説 |
| 台場の西側の堀は、何にあたりますか。 | 付け替えられた川 | 解説 |
| 南の出入口から入って北の出入口へ抜けるとき、途中で通る建物はどれですか。 | 番所 | モデル |

- 種別「解説」: クリックで出る解説に書かれた事実。提示ありの群が、解説を読んで学べたかを見る
- 種別「モデル」: 歩けば分かる事実(解説には書かない)。解説の効果と、空間の把握の効果を区別するための対照
- 解説の内容は `unity/KuzuhaDaiba/Assets/Scripts/ObjectDescriptions.cs`。**解説の文面を変えたら、種別「解説」の問題を必ず見直す**
- 解説を実際に読んだか(どの物をクリックしたか)は、アプリのログと参加者IDで確認する。読んでいない問題は、解析から分けて扱う

## 注意
- 8項目の根拠の強さは、`data/evidence.csv` の判断(私たちの解釈)による。問題を確定する前に、指導教員か第三者の確認を受ける
- 問題の出し方: ページ4の質問文に、ページ6の正解(石垣など)を出さない。順序の影響に注意
- ページ6の正解は、公的解説の要約と、解説の文面にもとづく。原資料での確認は未了
- SUSの日本語は、一般的な訳を参考にした言い換え。論文で引用する場合は、定訳の出典を確認する
- 体験時間とクリック数は、アプリ側の記録と、参加者IDで結びつける(フォームには含めない)
- 氏名・学籍番号・メールアドレスは集めない。「条件」は、実験者が指示する(ランダムに近い割り当て)
