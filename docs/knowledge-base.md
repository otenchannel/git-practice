# 楠葉台場跡 知識ベース(資料総合調査資料集 2026-10-12 版の要約)

出典: 利用者提供PDF「楠葉台場跡 資料総合調査資料集(LLM参照用リサーチ・コーパス)」(L04)。
公開情報の要約・書誌の整理であり、報告書本編・史料編・設計図の全文や全図版は含まない。S番号は `data/sources.csv`、Q番号は `data/open-questions.csv`、根拠区分は `data/evidence.csv` を参照。
引用・転載は最小限とし、**原資料に当たれていない事項を確定情報として扱わない**。

## 1. 基本情報
- 名称: 楠葉台場跡(くずはだいばあと)。「葛葉」ではなく「楠葉」。別称・旧称: 楠葉砲台、楠葉関門、八幡関門
- 所在地: 大阪府枚方市楠葉中之芝。淀川左岸の河川台場(海岸の台場ではない)
- 完成: 慶応元年(1865)。国史跡指定: 2011年2月7日(S01 S02 S03)
- 目的(公的説明): 京都守護職・松平容保の建言を背景に、幕府が京都防衛のため造営(S01)
- 面積: 約38,000㎡。ただし船番所の敷地と周囲の新設京街道を含む規模で、台場内部の面積ではない(S03 S06)
- 座標(DBの地点): 34.876275, 135.681419(WGS84)。史跡境界ではない(S11)
- 設計責任: 枚方市は「勝海舟が設計総責任者」と説明(S07)。文化庁解説は名指ししていない。役割を区別して一次史料・論文で検証する課題(Q・4.4)

## 2. 構造(公的解説ベース。寸法は原図面で要照合)
- 南面・西面: 大坂方面を向く稜堡式の主防御面。南面塁前に幅6間の堀、西面塁前に付け替えた放生川。堀は石垣造り
- 砲座3か所(南面塁1・西面塁2)、見張台は南面塁東端。砲の機種・口径は未確認
- 北面・東面: 比較的小規模な土手と溝(北側堀の幅は約4〜8mと案内板)
- 火薬庫: 周囲を土塁で囲む安全構造と案内板が説明。形状は未確定
- 番所・京街道: 京街道を台場内へ迂回させ関門機能を持たせた。南側土橋から南虎口→見切塁・番所→北虎口へ抜ける動線。番所前通路幅10間(約19.7m)、番所は梁行4間(約7.9m)×桁行8間(約15.8m)、棟高8尺(約2.4m)超(案内板の値)
- 時点レイヤーを分ける: 計画・設計時 / 1865年完成時 / 1868年前後 / 廃止後 / 発掘時 / 現況

## 3. 発掘調査(2008〜2009年度、土地区画整理事業に伴う)
- 報告された遺構: 堀・溝・道路・土塁・虎口・土橋橋台部。遺物: 土師器・須恵器・陶器・磁器・鉄器
- 文化庁解説: 南面堀石垣基底の根石列・胴木、南面虎口基礎、北面虎口土橋遺構、京街道の痕跡を確認
- 残存: 西端は京阪軌道敷・河川改修で消失。外郭線・南面堀は地割として良好に残り、平面は概ね設計図に準拠
- 未確定: 各土塁の天端高・傾斜・胸墻・木造立面・砲の仕様(本編の図版で確認するまで確定値にしない)
