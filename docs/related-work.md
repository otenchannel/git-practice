## 4. 本研究の4候補への示唆
| 候補 | 先行研究との重なり | 見立て(要検証) |
|---|---|---|
| ① 位置合わせの誤差見積り | 歴史地図のジオレファレンスの品質評価は存在 | 縮尺不明の手彩色図を、現存地物で縮尺決定し誤差を見積もる事例は特殊だが、手法としての新しさは小さい |
| ② 資料間の整合の検証・感度分析 | 今回の検索では、同じ主題の研究は見つからず | **空白の可能性**。寸法の食い違いが復元の形に与える影響を示す |
| ③ 導出過程の記録 | Extended Matrix、パラデータ、Apollonio らが先行 | 単独では新規性にならない。手段として使う |
| ④ 利用者への効果 | 表現方式の比較(3D)、VR+不確実性の研究が少数 | **VRで、複数の表現方式を比べ、推定と事実の識別を測る設計**は、空白の可能性。日本の近世遺跡での事例は見つからず |

**暫定の結論**: ③と「VRで根拠を色分けする」こと自体は、既にある。研究の主張は、②(資料が少ない対象での資料間整合と感度分析)と④(VRでの表現方式の比較と、日本の近世遺跡への適用)に置くのが現実的。
「適用・比較・検証」による新しさで足りるかは、先生の期待する水準による。報告で確認する。
