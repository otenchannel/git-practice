# 卒業研究計画書(骨子)

## 題目(仮)
幕末期河川台場「楠葉台場」のVR復元と、その理解促進効果の検証

## 背景
- 楠葉台場跡(大阪府枚方市楠葉中之芝)は慶応元年(1865)完成の西洋式稜堡式砲台。国指定史跡。
- 河川に築かれた台場として国内で唯一遺構が残るとされる(枚方市資料)。
- 現地は史跡公園として整備されているが、構造や運用は現地だけでは把握しにくい。

## 目的
1. 報告書・絵図・文献に基づき、根拠レベルを明示した3D復元をUnityで構築する。
2. VR体験が、図面・解説パネルと比べて構造理解や関心をどう変えるか評価する。

## リサーチクエスチョン
- RQ1: 根拠レベルを可視化した復元モデルは、どの程度の妥当性説明が可能か。
- RQ2: VR体験は従来資料に比べて空間理解・歴史的関心を高めるか。

## 手法
1. 資料収集・整理(`data/sources.csv`)
2. 復元要素の根拠管理(`data/evidence.csv`)
3. 地形・遺構・構造物のモデリングとUnity実装(`unity/`)
4. 被験者実験(VR群 / 図面・パネル群)。アンケート(SUS・没入感・関心)+理解度テスト
5. 考察: 復元の限界、文化財教育・観光への応用

## スケジュール(仮・期限が決まり次第調整)
| 期 | 内容 |
|---|---|
| 1 | 資料入手、先行事例調査、地形データ取得 |
| 2 | 現地調査・撮影、寸法抽出、根拠表作成 |
| 3 | モデリング、Unity実装(MVP) |
| 4 | 実験設計・倫理確認、予備実験 |
| 5 | 本実験、分析 |
| 6 | 論文執筆、発表準備 |
