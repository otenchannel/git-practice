# 提供地形図の縮尺の決定(2026-10-14)

前提: 用紙はA4、上が北(提供者の確認)。写真は未補正。縮尺の印刷表記は写真に写っていない。

## 方法
写真の地図は工事前(水田が広がる時期)のもので、現在の地図と建物はほぼ一致しない。そこで、**今も変わらない地物の距離**を国土地理院の標準地図タイル(z=18, 0.4899 m/px)で測り、写真上のピクセル距離と比べた(`tools/fetch_gsi_tiles.py`)。

| 測定 | 現在の地図 | 写真 | 縮尺 |
|---|---|---|---|
| 台場跡の東辺(北東角)〜京阪線路(最寄り点)。写真は内側の土手/外側の堀の線 | 171.0 m | 468 px / 494 px | 0.365 / 0.346 m/px |
| 南の東西道路: 京阪側の端〜南東の交差点 | 121.6 m | 350 px | 0.348 m/px |
| 平均 | | | **0.353 m/px(±3%)** |

- 二つの測定の方位差は0.6度で、「上が北」と整合する(回転補正はしない)。
- 紙面から: A4の辺の長さから紙面1pxは約0.150〜0.157 mm(台形歪みで場所により±3%)。0.353 m/px は縮尺約**1/2,300**に相当する。印刷時に拡大・縮小されたため、元の縮尺(1/2,000か1/2,500など)とは一致しない。**原本の縮尺表記があれば最終確認に使う(Q15)。**
- 番所は、この縮尺で地理院座標に置くと、DBの地点(34.876275, 135.681419)の西約62m・北約43mになる。台場の広がり(約300m)の内側で、矛盾はない。

## 限界
- 台場の東辺は、写真の彩色線と現在の公園境界を対応させており、約±4%の幅がある。
- 写真の台形歪み(紙面の水平方向で約7%)は補正していない。場所によって縮尺が数%ずれうる。
- 手彩色された領域は、実際の寸法(番所15.8m×7.9mなど)より小さめに塗られている。構造物の大きさから縮尺を逆算すると過大になる(以前の仮値0.40はこれが原因)。

## 再計算
`python3 tools/build_provisional_mesh.py ... --scale <新しい値>` で全体に反映される。
